이 브라우저에 남은 글을 확인하는 중…
새 주소에서 글 가져오기
  1. 위 버튼을 누르면 새 파티노트가 열려요.
  2. 가져오기 → 합치기를 누르면 쓰던 글·책·설정이 그대로 옮겨져요.
  3. 앱으로 쓰고 있었다면, 새 주소에서 앱 설치(홈 화면에 추가)를 다시 하고, 이 옛 앱은 지워 주세요. (PC 크롬은 이 창 오른쪽 위 ⋮ → 제거)
아이폰·아이패드 이사하는 법

아이폰의 홈 화면 앱은 글이 그 앱 안에만 있어서, 백업 파일로 옮겨요.

  1. 위 버튼을 누르고, 공유 창에서 파일에 저장을 골라요.
  2. 사파리로 party-note.com을 열고, 공유 버튼 → 홈 화면에 추가로 새 파티노트를 설치해요.
  3. 새 파티노트에서 메뉴 → 백업 → 가져오기 → 저장한 파일을 고르고 합치기를 눌러요.
  4. 잘 옮겨졌으면 이 옛 앱 아이콘을 길게 눌러 앱 삭제해요.

이 주소에 남은 글은 지워지지 않아요. 여러 번 옮겨도 겹치지 않아요.
