## 한눈에 보기

- 설치 없이 **브라우저에서 바로** 열리고, 홈 화면에 추가하면 **앱처럼** 쓸 수 있어요.
- 글은 **내 기기 안에만** 저장돼요. 인터넷이 끊겨도 쓰고 읽을 수 있어요.
- 메모를 모아 **책**으로 엮고, **챕터**를 나누고, **표지**를 붙일 수 있어요.
- 완성한 책은 **전자책(.epub)·워드(.docx)·텍스트(.txt)** 로 내보낼 수 있어요.
- 구글 계정으로 로그인하면 **클라우드에 백업**해 둘 수 있어요.
- 무료이고, 광고와 외부 방문 분석 도구가 없어요.

## 앱으로 설치하기

| 기기 | 방법 |
|---|---|
| 안드로이드 (크롬·삼성 인터넷) | 메뉴 → **앱으로 설치** 버튼, 또는 브라우저 메뉴의 '홈 화면에 추가' |
| 아이폰·아이패드 (사파리) | 공유 버튼 → **홈 화면에 추가** |
| PC (크롬·엣지) | 주소창 오른쪽의 설치 아이콘 |

설치하면 주소창 없이 앱처럼 열리고, 오프라인에서도 열려요.

## 메모 쓰기

- 오른쪽 위 **+** → **메모** 로 새 메모를 써요. 제목 칸은 따로 없고, **본문의 첫 줄**이 목록에 보여요.
- 쓰는 동안 **8초마다 임시 저장**돼요. 앱이 갑자기 닫혀도 다음에 쓰기 화면에서 '임시 저장한 글 불러오기'로 되살릴 수 있어요.
- 쓰기 화면 위쪽에 **글자 수**(공백 포함·제외)와 대략의 크기가 보여요.
- 읽는 화면의 **본문 복사** 버튼으로 연재처에 바로 붙여 넣을 수 있어요.
- 메모의 **⋯** 메뉴: 고치기 · 책에 넣기 · 비공개로 하기 · 삭제

## 책 만들기

- **+** → **책** 으로 책을 만들고, 그 안에서 **새 쪽 쓰기** 를 하거나 써 둔 **낱장 메모를 넣을** 수 있어요.
- 쪽 목록은 **오름차순 / 내림차순** 으로 바꿔 볼 수 있어요. (모든 책에 같이 적용)
- 마지막으로 읽은 쪽에 **책갈피**가 꽂혀서 **이어 읽기** 버튼으로 바로 돌아갈 수 있어요.
- 쪽을 읽을 때 아래쪽 막대에 **얼마나 읽었는지**가 차올라요. 앞쪽·뒤쪽 버튼으로 넘겨요.

### 쪽 순서 바꾸기
쪽의 **⋯** 메뉴에서
- **앞쪽으로 / 뒤쪽으로** — 한 칸씩
- **쪽 번호로 옮기기** — 번호를 적고 'N쪽 앞에 / 뒤에' 를 골라 한 번에 옮겨요 (3쪽 이상인 책)
- **책에서 빼기** — 낱장 메모로 돌아가요

### 챕터 나누기
- 책 화면의 **챕터 구분 추가** 로 챕터 제목을 적고, 몇 쪽부터 시작할지(또는 맨 끝) 골라요.
- 쪽 목록에 `── 2장. 가을 ──` 같은 구분선이 생기고, 그 챕터의 첫 쪽을 열면 본문 위에 챕터 제목이 보여요.
- 구분선의 **⋯** 에서 제목 고치기 · 위치 옮기기 · 챕터 구분 없애기를 할 수 있어요.
- 맨 끝에 만든 챕터는 **다음에 새로 쓰는 쪽부터** 시작해요.

### 표지
- 책의 **⋯** → **표지 사진 넣기**. 웹소설 표지와 같은 **1 : 1.43** 비율(400×572)로 맞춰져요.
- 문피아(400×572)·조아라(700×1000) 표지를 그대로 써도 잘 맞아요.

### 책 정보 (ⓘ)
쓴 기간, 분량(쪽·글자 수)을 보여 주고, 여기서
- **완결하기** 🎉 / **연재 중지하기** / **연재 재개하기**
- **책 잠그기** — 실수로 지우지 않게 삭제 메뉴를 숨겨요
- **비공개로 하기**
- **책 내보내기**

를 할 수 있어요.

## 책 내보내기

책 정보(ⓘ) → **책 내보내기** 에서 형식을 골라요.

| 형식 | 쓰임 |
|---|---|
| **선물용 파일 (.json)** | 다른 파티노트 사용자가 '가져오기'로 받을 수 있어요. 표지와 챕터도 같이 가요. |
| **전자책 (.epub)** | Apple Books, Google Play 북 등에서 읽어요. 표지·차례(챕터 제목)·저자명이 들어가요. |
| **워드 문서 (.docx)** | 워드, 구글 Docs(드라이브에 올려 열기), 한글에서 열려요. 챕터마다 새 페이지로 나뉘어요. |
| **텍스트 (.txt)** | 어디서나 열리는 순수 글자 파일 |

전자책의 **저자명**은 메뉴의 '저자명'에서 정해 둘 수 있어요.

## 찾기와 정리

- **검색** (돋보기) — 본문과 책 제목, 챕터 제목에서 찾아요. 띄어 쓴 낱말이 모두 들어간 글만 보여요.
- **필터** — 전체 · 책 · 메모 · 즐겨찾기(★) · 휴지통
- **즐겨찾기** — 메모나 책을 열고 ☆ 를 누르면 맨 위로 올라와요.

### 휴지통
- 지운 메모와 책은 바로 사라지지 않고 **휴지통**에 30일 동안 남아요.
- 휴지통에서 눌러서 **되살리기 / 영구 삭제** 를 골라요. 책을 되살리면 함께 지운 쪽도 같이 돌아와요.
- 30일이 지나면 저절로 지워져요.

### 비공개 칸
- 메모나 책을 **비공개로 하기** 하면 전체·검색에서 빠지고 **비공개 칸(눈 가림 아이콘)** 에만 보여요.
- 메뉴의 **비공개 칸 → 숨기기** 로 하면 비공개 글이 어디에도 보이지 않아요. (지워지는 것은 아니고, 암호로 잠그는 것도 아니에요)

## 백업과 복원

글은 이 기기의 브라우저 저장소에만 있어요. **기기를 바꾸거나 브라우저 데이터를 지우기 전에 꼭 백업해 주세요.**

| | 백업 (내보내기) | 복원 (가져오기) |
|---|---|---|
| **파일** | 메뉴 → 백업 → 내보내기 → `.json` 파일 저장 | 가져오기 → 파일 고르기 |
| **클라우드** (로그인 시) | 내보내기 → **클라우드에 백업** | 가져오기 → **클라우드에서 복원** → 목록에서 고르기 |

- 클라우드 백업은 한 사람당 **최근 3개**까지 보관해요.
- 복원은 **덮어쓰기가 아니라 합치기**예요. 백업에만 있는 글은 돌아오고, 양쪽에 있는 글은 더 최근에 고친 쪽이 남아요.
- 로그인은 메뉴의 **계정 → Google 계정으로 로그인**. 비밀번호는 파티노트가 받지 않아요.
- 탈퇴는 메뉴의 **계정 → 탈퇴하기**. 클라우드 백업과 계정 정보가 지워지고 구글 계정과의 연결도 끊어져요. 기기 안의 글은 그대로 남아요.
